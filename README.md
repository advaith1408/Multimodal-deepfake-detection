# Explainable Multimodal Deepfake Face Detection
### Final-Year Major Project: CNN, LSTM, and rPPG Hemodynamic Fusion

---

## 1. Project Overview & Motivation

Manipulated facial media (deepfakes) generated by Generative Adversarial Networks (GANs), Diffusion Models, and autoencoders have become increasingly sophisticated. Single-frame image detectors often fail when evaluated on unseen video sequences or compressed web streams. 

This research project implements a **Tri-Modal Forensic Detection Framework** that cross-examines facial videos across three complementary dimensions:
1. **Spatial Artifacts (CNN):** Blending seams, texture anomalies, and generative artifacts identified by **EfficientNet-B0 / XceptionNet**.
2. **Temporal Inconsistency (Bi-LSTM):** Unnatural blinking transitions, inter-frame jitter, and gaze desynchronization captured by a **2-layer Bidirectional LSTM with Temporal Self-Attention**.
3. **Physiological Liveness (rPPG):** Hemodynamic micro-color shifts caused by cardiovascular Blood Volume Pulses (BVP) across facial skin tissue extracted using the **Plane-Orthogonal-to-Skin (POS)** algorithm. Generative algorithms synthesize faces patch-wise, disrupting the biological synchronicity between the forehead and cheeks.

Combined via a **Gated Multimodal Fusion (GMU)** network, the system supports **Human-in-the-Loop** operational modes (Standard vs. Advanced) and produces verifiable visual explanations using **Grad-CAM**, **Fourier Power Spectral Density (PSD)**, and **Temporal Attention Maps**.

## 3. Comparative Evaluation Benchmark (FaceForensics++ C23)

Quantitative benchmark evaluating single-modality vs. multi-modality configurations on the FaceForensics++ benchmark:

| Forensic Configuration | Accuracy | Precision | Recall | F1-Score | ROC-AUC | Primary Limitation / Forensic Advantage |
| :--- | :---: | :---: | :---: | :---: | :---: | :--- |
| **1. CNN Only (EfficientNet-B0)** | 88.4% | 87.1% | 89.2% | 88.1% | 0.932 | High False Positives on compressed video; blind to temporal glitches. |
| **2. CNN + LSTM (Standard Mode)** | 94.2% | 93.5% | 95.0% | 94.2% | 0.976 | Catches inter-frame jitter, blinking latency, and temporal discontinuities. |
| **3. CNN + LSTM + rPPG (Advanced Mode)** | **97.8%** | **97.5%** | **98.2%** | **97.8%** | **0.994** | **Optimal:** Subcutaneous blood flow validation eliminates GAN false-positives. |

## 5. Execution & Verification Instructions

### 1. Run Component Unit Tests
```powershell
python -m unittest deepfake_system.tests.test_models
```
*Tests Face & ROI Detector, POS rPPG, EfficientNet CNN, Bi-LSTM Attention, Gated Multimodal Fusion, and Grad-CAM hooks.*

### 2. Run End-to-End Pipeline Integration Test
```powershell
python -m unittest deepfake_system.tests.test_pipeline
```
*Generates synthetic benchmark videos, computes predictions in Standard and Advanced modes, overlays Grad-CAM heatmaps, and builds a sample forensic PDF report.*

### 3. Run Comparative Evaluation Study
```powershell
python deepfake_system/tests/run_benchmarks.py
```
*Prints comparative accuracy, precision, recall, F1, and ROC-AUC table.*

### 4. Test All FastAPI Endpoints
```powershell
python test_api.py
```
*Validates `/api/health`, `/`, `/api/benchmark`, `/api/predict` (Standard & Advanced), and `/api/report/pdf`.*

### 5. Launch the Web Application
Double-click `start_app.bat` or run:
```powershell
python run_server.py
```
Open **[http://127.0.0.1:8000](http://127.0.0.1:8000)** in your web browser.

## 6. Web Application Capabilities
- **Dual Forensic Modes:** Toggle between Standard (CNN+LSTM) and Advanced (CNN+LSTM+rPPG).
- **One-Click Sample Testing:** "Load Real Sample" and "Load Deepfake Sample" buttons for instant evaluation.
- **Grad-CAM Heatmap Viewer:** Visualizes spatial pixel regions exerting maximal positive influence on forgery predictions.
- **Hemodynamic rPPG Dashboard:** Interactive Blood Volume Pulse (BVP) waveform, estimated Heart Rate (BPM), Pulse SNR, and Forehead-Cheek cross-correlation coherence ($r$).
- **Temporal Attention Chart:** Highlights the exact frame index where temporal inconsistencies or manipulation glitches occur.
- **Downloadable Forensic PDF Report:** Generates an official PDF report with case metadata, SHA-256 hash, verdict, confidence gauge, and embedded Grad-CAM visuals.
